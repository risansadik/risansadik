I am a results-driven **Full-Stack Developer** based in Calicut, Kerala, with a strong foundation in modern web technologies including **React, Next.js, Node.js, and TypeScript**. My expertise lies in designing end-to-end systems, from intuitive frontend interfaces to robust, secure backend architectures. 

Whether it's integrating **LLM-powered AI layers** (Structify AI), architecting **Clean Architecture backends** (reNove), or building **full-scale e-commerce platforms** (Brossoc Clothing), I am passionate about writing clean, maintainable code that solves real-world problems.
